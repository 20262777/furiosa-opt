# rngd-kernels

Low-level vISA kernel library for FuriosaAI **RNGD** (Tensor Contraction Processor),
built directly against the [`furiosa-opt`](https://github.com/furiosa-ai/furiosa-opt)
Virtual ISA.

Every operation is developed as a **rung** on a ladder — from `add` up to a working
attention block — and each rung ships with its own spec, torch ground truth, test,
schedule dump and run report. The cycle and the ladder live in
**[`PIPELINE.md`](./PIPELINE.md)**.

## Quick start

```bash
./pipeline.sh ladder          # every rung: ground truth -> typecheck -> test -> schedule -> report
./pipeline.sh all <op>        # one rung, end to end
./pipeline.sh check <op>      # mapping/shape errors only (~1s)
```

Ground truth is generated by torch into `data/` (gitignored), so run `gt` before a bare
`cargo test`. `pipeline.sh all` / `ladder` do that for you.

## Status

| # | op | new concept | status |
|---|---|---|---|
| 01 | `add` | `begin_interleaved` → `unzip` → `clip_zip` | ✅ |
| 02 | `mul` | VRF operand + Float cluster (4-way) → `narrow`/`widen` | ✅ |
| 03 | `dot` | Contraction Engine: packet tree + time accumulator | ✅ |
| 04 | `gemv` | output axis in `Slice`; DMA broadcast of the stationary operand | ✅ |
| 05 | `gemm` | both output axes in `Slice`, `Lane` carries `J`; 100% MAC utilisation | ✅ |
| 06 | `reduce_sum` | intra-slice + inter-slice reduce | ✅ |
| 06b | `reduce_sum_ragged` | row-wise reduce over a non-factoring axis; VCG masking | ✅ |
| 07 | `rmsnorm` | `stash` for `x*x`, multi-pass, ALU budgeting | todo |
| 08 | `softmax` | max → exp → sum → div; `TagMode::Comparison` masking | todo |
| 09–11 | `qk_matmul` / `attn_output` / `attention` | composed attention block | todo |

All passing rungs are **bit-exact** against their torch reference on the `emulation`
backend.

## Layout

```
src/ops/<op>/{mod.rs, spec.md, ground_truth.py}   kernel + design record + reference
tests/op_<op>.rs                                  numeric comparison
data/<op>/                                        generated ground truth (gitignored)
results/<op>/{report.md, schedule.json}           run record
```

## Requirements

- Rust `nightly-2026-05-01` (pinned in `rust-toolchain.toml`; `cargo-furiosa-opt` is
  ABI-locked to it)
- `cargo-furiosa-opt`
- Python with `torch` + `safetensors` for the ground-truth generators
- No NPU hardware or Furiosa SDK: the pipeline uses only the `typecheck` and `emulation`
  backends

## Relationship to the surrounding tree

- `../furiosa-opt/` — the upstream Virtual ISA, docs and examples
- `../lab/` — a pristine `base-template` scaffold kept for reference; this package does
  not depend on it
